# \_system-docs — reserved for Totalum

This folder belongs to Totalum (plan 06 §2.1, A7.13). Totalum rewrites it on every docs update, so an edit made
here does not survive. It is reference material for the coding agent: how the database, authentication, the SDK
and the build work in this project.

- Never edit, move or delete anything in this folder.
- It is not part of the app: it is never built and never deployed.
- Your own documentation goes in `project-docs/`. A `docs/` folder, if you create one, is yours and Totalum never
  touches it.
